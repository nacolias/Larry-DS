# larry/bench - the measurement harness and probes

Everything here was written on Larry and runs there as written. The scripts assume `/opt/ai/dsv41` (the checkout at
`/opt/ai/dsv41/xolotl`), the service on `172.23.0.1:18080` (an A/B server on `:18081`), and the API key in
`/opt/docker/vllm/.env`. Adjust those to reuse them. Run outputs, logs and datasets are not included.

| dir | what |
| --- | --- |
| `speed/` | the A/B harness: `abw.sh` (a window: waits for the service to be idle, stands in on its port, runs each config, brings the service back), `tabx.sh` / `abx.py` (fresh prompts, edits, decode), `agentx.py` (a synthetic agent session: the repo's own source and fixed assistant turns), `opprof.sh` (card 0's per-op profile, `GGML_SYCL_OP_PROF=1`), `pipesum*.py` / `calltl*.py` (pipeline and call timelines), `nicebuild.sh` (a build frozen while the service has requests) |
| `quality/` | AIME 2026 and GPQA-Diamond runners (`aime.py`, `gpqa.py`; `mkdata.py` / `mkgpqa.py` build the inputs, which are not included) |
| `qv/` | the quant-vs-original comparison: DeepSeek's FP8/FP4 release teacher-forced on the CPU (`qv_teacher.sh`), the engine's logits on the same rows (`qv_engine.sh`), `qv_score.py`; `qv_score.json` / `teacher_summary.json` are that run's results |
| `provenance/` | the weight checks against the official and the dealignai repos (`prov2.py`, `prov3.py`; `prov3.log` is the result) |
| `engram/` | `engram_epg.py` (the paged Engram copy: convert / verify), `iops.c` (random-read rates), `test_engpg.cpp` |
| `cpu/` | `ptq1_rows_bench.cpp`: the CPU pool's PTQ1_0 (ternary) rows kernel against the engine's, every output compared bit for bit, ns a row at 1-4 tokens (`patch-ptq1rows.py`) |
| `conc/` | concurrent sessions: `s0test.sh` / `s1test.sh` (a private server: needles, the tool call, `reusetest.py` - the park pool, the rewind - `seqtest.py` - two resident conversations - and `concurtest.py`, requests at once), `twoessays.py` (two long answers at once), `s2test.sh` / `jointcheck.py` (batched decode: the staged engine of `s2build.sh`, answers alone vs at once), `wb.sh` (pass cost by width, `patch-widthbench.py`), `cpulog.sh` / `cpulog_stats.py` (the CPU pool's experts a pass, by format), `vmm_span_probe2-4.cpp` / `probe-span2-4.sh` (card 0's growing VMM read by the other cards), `lazyab.sh` / `r1m-stage.sh` (the lazy KV map's replica check: `patch-tpsynclog.py`), `r1m.sh` (long needles in either slot, `STRATA_ADDR_LOG`), `vmm_span_probe.cpp` (peer copies across VMM allocations) |
| `li/` | the prompt indexer's kernels: `topk2_test.cpp` (the two-stage top-k of patch-topk2.py against the radix select: sets and times; `topk2.sh`), `lifbf_probe.cpp` (the fused kernel, fp16 copies against bf16 in place; `lifbf.sh`, `lif_kernel.inc` = the kernel as the engine has it) |
| `longctx/` | long contexts: `xbuild.sh` / `xinstall.sh` (an engine change staged beside the service, then installed), `r1m-ra.sh` (131K + 984K needles on a staged engine with the replica check), `ra-ab.sh` (patch-roomahead.py's read-ahead off / on, with the host's reclaim counters), `prof1m.sh` + `profdiff.py` (card 0's op profile over a long prompt, by depth), `tsvc2-ra.sh` (the service checks after an install), `pp-ab.sh` / `lt1m.sh` (long needles under each configuration) |
| `vision/` | pictures: `venc_test.py` (one picture through the encoder, started as the server starts it), `vtest.sh` / `vtest.py` (a test server with the `"vision"` section: two cards through both APIs, a follow-up that reuses the picture, a second picture that must not) |
| `fa/` | the prompt attention: `test_fsa.cpp` (the fused kernel `fsa_kernel.inc` = patches/fsa_kernel.inc against the service path - KGATHER + oneDNN's SDPA - and a double reference; `build_fsa.sh`, `run_fsa.sh`, `run_fsa2.sh` = its phases skipped in turn), `mqa_mb.cpp` (XMX operand paths: local / global, each layout), `test_sdpa_blk.cpp` (oneDNN's SDPA over query blocks), `selunion.py` + `dsel.sh` (how much consecutive queries' selections overlap, from patch-dumpsel.py's dumps) |
| `dqb/` | the expert GEMMs: `bench_dqgemm.cpp` (xe_dqgemm alone at a call's shapes), `dqmt.sh` + `bench_dqgemm_mt.cpp` / `xe_dqgemm_mt.cpp` (its tiles 128 / 160 / 192 token rows tall), `dqv2.sh` + `bench_dqgemm_v2.cpp` / `xe_dqgemm_v2.cpp` (v1 against v2 - patch-dqv2.py's kernel - bit for bit and timed), DMA / P2P / allocation probes |
| `fm*/`, `gr/`, `fuse/`, `xe/` | SYCL kernel probes and benchmarks: dequant GEMMs, flash attention, fast mat-vec, staging rings, copies, P2P |
| `tp/`, `engine0/`, `engine1/` | the tensor-parallel core's probes and benchmarks (`engine1/vmm_remap.cpp`: the remapped-VMM peer-write hazard) |
| `*.cpp` at the top | first-day probes (launch, submit, copy, pin, dp4a, clock); `early/`: the first days' one-shot runners |
